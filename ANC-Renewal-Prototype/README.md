# ANC Renewal Desk Prototype

Prototype สำหรับ Part 2 ของแบบทดสอบ AI Transformation Associate

เปิดไฟล์ `index.html` ในเบราว์เซอร์ หรือรัน static server จากโฟลเดอร์นี้ เช่น

```bash
python3 -m http.server 4173
```

ตัวอย่างฟังก์ชันที่มี

- คำนวณ Priority ระดับ HIGH, MEDIUM, LOW
- แสดงเหตุผลที่จัดลำดับ
- แนะนำการทำงานต่อไปสำหรับ AE
- เลือกข้อเสนอจำลองที่เหมาะกับเคส
- สร้างข้อความสำหรับเริ่มติดต่อลูกค้า
